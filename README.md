# Todo App — 前后端分离

将原本单文件 HTML Demo 重构为前后端分离架构。

- **前端**：React 18 + TypeScript + Vite + Tailwind CSS
- **后端**：Spring Boot 3.3 + Java 17 + Spring Data JPA
- **数据库**：Supabase Postgres（直连，不通过 Supabase JS SDK）
- **设计系统**：基于 `ui-ux-pro-max` skill 输出 —— Minimal Single Column / Flat Design / Plus Jakarta Sans

## 目录结构

```
test-website/
├── frontend/          # React 应用（端口 5173）
├── backend/           # Spring Boot 应用（端口 8080）
├── legacy/            # 旧的单文件 HTML 版本（仅作存档）
└── .github/workflows/ # 旧 GitHub Pages CI（前后端分离后已不适用，可后续删除）
```

## 一、Supabase 数据库准备

如尚未建表，登录 Supabase Dashboard → SQL Editor 执行：

```sql
create table if not exists todos (
  id bigint generated by default as identity primary key,
  text text not null,
  done boolean default false not null,
  created_at timestamptz default now() not null
);
```

并在 **Project Settings → Database** 拿到数据库密码（不是 anon key）。

## 二、启动后端

```bash
cd backend

# 设置数据库密码（每个新终端都要设）
export SUPABASE_DB_PASSWORD='你的Supabase数据库密码'

# 启动（首次会下依赖，慢一些）
mvn spring-boot:run
```

后端默认监听 `http://localhost:8080`，提供以下接口：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/todos` | 列表（按创建时间升序） |
| POST | `/api/todos` | 新增，body `{ "text": "..." }` |
| PATCH | `/api/todos/{id}` | 更新完成状态，body `{ "done": true }` |
| DELETE | `/api/todos/{id}` | 删除 |

### 快速 API 自测

```bash
curl http://localhost:8080/api/todos
curl -X POST -H 'Content-Type: application/json' -d '{"text":"learn spring"}' http://localhost:8080/api/todos
```

## 三、启动前端

打开**新终端窗口**：

```bash
cd frontend
npm install      # 首次执行
npm run dev
```

访问 `http://localhost:5173`，Vite 已配置 `/api` 代理到后端 8080。

## 四、生产构建

```bash
# 前端
cd frontend && npm run build       # 产物在 frontend/dist/

# 后端
cd backend && mvn clean package    # 产物在 backend/target/*.jar
java -jar backend/target/todo-backend-0.0.1-SNAPSHOT.jar
```

## 五、关于实时同步

旧版本（`legacy/index.html`）通过 Supabase JS SDK 的 WebSocket 实现了多端实时同步。

新版本走 Spring Boot 中转，**默认无实时**，多人/多端打开需手动刷新。

如需恢复实时能力，可选：

- 前端绕过后端直连 Supabase Realtime 监听变更（写仍走后端）
- Spring Boot 自行实现 SSE / WebSocket 推送
